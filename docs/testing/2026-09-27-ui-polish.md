# UI polish verification

Approved scope: [revision 5 contract](../mockups/approved/2026-09-25-ui-polish.md).

## Implementation

Web and native now use compact unboxed tapes, handwritten tape names, matching
skeletons, contextual empty/error art, compact source badges, quiet inline retry,
custom feedback marks and compact text-only confirmations. Tape settings provides
48 small circular swatches. New mixes receive a stored random colour; existing
mixes receive a stable varied backfill. Blank playlist names cannot be submitted.
The right-reel crop is exported to every iOS app-icon size; web uses the whole
cassette favicon. Colour changes use the real owner-scoped session API.

## Review fixes

- Preserve saved colour across queue snapshots and stale collection refreshes.
- Keep Closet rows compact without a second tape/open button.
- Retain playlist drafts and errors; trap modal focus and prevent busy dismissal.
- Make Undo one-shot and dismiss its toast immediately.
- Keep normal-size feedback at 44 points, with room for assistive text sizes.
- After an uncertain colour save, selecting the original colour writes again.
