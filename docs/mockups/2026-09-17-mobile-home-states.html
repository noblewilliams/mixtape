Home, in every state it can be in.

Home was approved as part of the shell on September 17. This board covers what changes on it: typing, the playlist attachment and its picker, starting a mix, failures, the Spotify waiting state, idea pills while they load and when there are none, the pill long-press, and the reserved voice state. The base layout, dock and gradient are the approved ones and are not up for review again here.

Truth boundaries. Starting a mix currently waits on the server for the whole first turn (20–40 s) before the conversation opens, so the "starting" state stays on Home. Voice input is planned before launch; its frame is marked Planned and shows only the listening state. Import sheets opened from Home (a ZIP handed over from Files or Mail) belong to the import board.
