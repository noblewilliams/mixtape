Revised layout study · artwork + direct manipulation

The mix should look and move like music.

The first board treated the queue like metadata. This pass makes the covers, order, and physical act of rearranging the main experience.

A · Artwork rail B · Mix workspace C · Artwork shelf States
What the Apple Music reference gets right: the queue is always legible as music because artwork anchors every row, and the dragged track visibly leaves the rail while the destination stays clear. This board borrows that behavior while keeping Mixtape’s lighter tape-and-glass language.

Mobile behavior
Explicit reorder mode
Touch drag competes with scrolling, so the handle first enters reorder mode; only then does vertical movement rearrange.
Keyboard and switch access
Focused move handles accept arrow keys and announce the new track number. No drag gesture is required.
Reduced motion
The lifted row keeps its border and label but does not rotate or travel.
Implementation boundary: approval covers layout, artwork sizing/fallbacks, pointer and keyboard reorder feedback, the stale-version recovery message, desktop behavior, and the mobile sheet. It does not yet choose remove/swap menus or change the DJ’s automatic sequencing rules.
