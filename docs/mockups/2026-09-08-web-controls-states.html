A little more control.

What the DJ remembers, the mixes you keep, and the playlists that inspire you. Four additions to the existing Mixtape web app. All content is invented; buttons only switch review states.

Remember deliberately

“What the DJ knows” is reachable from the existing account area. Forget uses a confirmation, because a deleted note cannot be restored by the current API.

Keep navigation quiet

Tap a mix name to edit it in place. Swipe left to archive, like removing a song. A minimal anchored action remains available for keyboard use.

Two different choices

A compact picker floats above the composer. The selected playlist appears as a small text attachment inside the input; open it to replace or adjust, or detach it with ×. Personal curation remains a separate choice.

Decision requested

Review the revised modal, dismissible action popover, inline renaming, swipe archive, and floating playlist attachment across themes and screen sizes. The recommendation keeps the existing shell and adds focused controls instead of a new settings section. Tradeoff: memory takes one extra step through the account menu.

Approval covers these four web features only. Existing Sources/import screens, native playlist editing, and production writes retain their separate contracts.
