# Compact Account

Approved November 4, 2026: “approved”, following the explicit request to retain
an icon beside Delete account.

Board: [Account compact](../2026-11-04-account-compact.html).

Native Account keeps the prism, background and grouped surfaces. Actions align
at the trailing edge; Login methods uses a quiet small heading with Refresh
beside it. Provider status and Last used share a line when space permits. The
last-method explanation sits below the group. Delete account retains its trash
icon and destructive colour. Names and metadata may wrap at large text sizes;
44 pt actions, editing, auth and deletion semantics remain intact.

Covers 320–430 pt widths, light/dark and 200% text. Supersedes the Account row
spacing and status arrangement in prior boards, not their interaction contracts.
Implementation owner: client/lib/presentation/screens/account_screen.dart.
Browser verification of the HTML was blocked; Flutter rendering is checked
separately during implementation.
