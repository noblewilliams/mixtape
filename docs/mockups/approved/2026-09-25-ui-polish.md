# Approved mobile and web polish — revision 5

Approved September 25, 2026: “everything's approved.”
Board: [UI polish, revision 5](../2026-09-25-ui-polish.html).

## Locked direction

- App icon: A's full-bleed crop around the **right** cassette reel and prism
  stripes, using the original artwork without mirroring. Web favicon: complete
  simplified cassette. No separate container behind the app's cassette crop.
- Mix rows: 80 px unboxed cassettes, shadow on the artwork, distinct shell colours,
  a handwritten single-line mix name on the cream label (truncate long names).
  The full name remains readable and accessible beside the illustration.
- Pick a random colour once at mix creation and persist it. Tape settings is a
  compact modal with 48 named colours, 20 px round swatches in 44 px targets.
  Selection persists; no random reassignment on render, reopen or another device.
- Skeletons follow the cassette silhouette, title and time. Keep titles and
  navigation visible during loading; retain loaded content when refresh fails.
- Web titles use mobile's system-font 28 px heavy treatment. Handwriting is for
  the mixtape wordmark and tape inscriptions. Navigation says **Mixes** and
  **Library**, with icons; Make a mix is a compact sidebar action.
- Added music sources use small logo badges. Apple Music remains recognizable;
  Spotify is honestly labelled as an import rather than a live connection.
- Empty states use contextual illustrations in the cassette material/palette:
  cassette for mixes/music, brain for saved preferences, disconnected audio lead
  for load failures. Shared placement and at most one relevant action.
- Retry sits at the trailing edge of the refresh message, in a quiet outlined
  control. Subtitle is smaller with a 3 px gap; no extra stacked action row.
- Toasts are compact/content-sized, 44 px at normal text size, with a 3 px prism
  bottom edge. Success/error/info use the approved custom marks. Error keeps the
  split-stop icon; success is an open chamfered frame/tick; info a split-frame i.
  Undo has small bold text, no underline, and fits the same toast height.
- Preference confirmation and create-playlist dialogs are compact and text-only:
  no illustrations or decorative stripe, small actions, tight spacing, preserved
  draft on failure. Whitespace-only playlist names disable Create playlist.

## Accessibility and platform behavior

Light/dark, narrow/desktop web, large text, reduced motion and all 20 preview
states are approved. Swatches expose names and selected state; status is not
colour-only. Touch targets stay usable even when visuals are small. Toasts grow
as a group at large text sizes; never clip content solely to force 44 px.
Native retains its four-tab shell and native/frosted dock implementation. Web
retains its sidebar shell. Neither platform should obscure playback/navigation.

## Rejected alternatives / superseded decisions

Full cassette inside an app-icon container, the left-reel crop, square tape tiles,
large tapes, full-row source blocks, generic rectangular skeletons, handwritten
web page headings, tall Undo toast, left toast stripe, and graphic-heavy dialogs
were rejected through revisions 1–4. This supersedes the September 18 one-cassette
empty-state and wordmark-only handwriting rules only for these approved surfaces.
Earlier approved records remain intact. Other tape-material/rack/landing boards
in this directory are outside this approval and implementation scope.

## Owners and verification boundary

Native: presentation foundation/widgets/screens and DJ session data/provider.
Web: shared components, styles, API mapper and session controls.
Backend: sessions schema, creation, owner-scoped PATCH and API responses.
Branding: iOS AppIcon asset catalog and web favicon.

The user reviewed the board in their browser and approved it. Automated browser
opening of the local file was blocked; the preview's syntax/runtime/assets were
checked, but agent-side visual rendering was not verified. Implementation tests,
builds and device/browser visual acceptance are tracked separately. Production
migration and release have not been authorized by this design approval.
