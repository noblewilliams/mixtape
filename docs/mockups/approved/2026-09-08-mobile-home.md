# Approved native Home — revision 2

Approved September 8, 2026: founder replied “approved” to the revised Home.
Board: [native parity states](../2026-09-08-mobile-parity-states.html).

Root Home has no back arrow, Playlist shortcut, Open buttons or row dividers. It shows a new-mix input with rotating example prompts, Active/Archived tabs and tappable mix rows. Rename is an anchored row action and activates inline editing; swipe left archives with Undo and durable restoration. Examples never overwrite text; pause rotation on focus, input, inactivity and reduced motion. Other destinations remain in a compact global menu.

Covers Home and its rename/menu/archive/empty/error states, system themes, narrow/tablet sizes, large text and reduced motion. This supersedes the first mobile Home design. Other parity screens retain their separate approval status. No provider or release actions are authorized by this design approval.
