Web layout study · 2026-08-31

A wider home for the mix.

Three ways to remove the permanent right sidebar, give track context more room, and return the conversation to full width. Each frame is interactive: use the mix count or close control to compare open and closed behavior.

A · Corner canvas B · Bottom deck C · Focus card States
Recommendation: A, the corner canvas. It behaves most like a floating widget: the conversation owns the normal layout, the mix opens beside the point of entry, and the wider row can finally show why each track belongs. The cost is temporary overlap while it is open.
A · Recommended

Corner canvas — anchored, wide, and easy to dismiss

A 650px floating canvas opens from the track-count control. Track title, artist, reason, and duration sit on one row; playback stays in a compact action column.
