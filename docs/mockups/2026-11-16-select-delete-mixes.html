Select and delete mixes

Tick several mixes, then archive or permanently delete them in one go. Built on the approved shared mixes Mixes rows and the WhatsApp chat-list direction from 9 November (swipe actions, slim Archived row). Server endpoint POST /sessions/delete is written and tested; no client code yet.

PlannedDelete = eject glyph (the transport rule), Archive keeps its box glyph. All content is made up.
Open questions for you (my pick is drawn; say if you want the other)
  1. Way in on iOS. A ⋯ glass circle at the top of Mixes with Select mixes, plus Select in each row’s menu (S1). Alternative: row menu only, so the Mixes header stays bare.
  2. Shared mixes in select mode are dimmed and can’t be ticked (they have their own Remove). Alternative: let them be ticked, and Delete removes your save of them.
  3. Single delete. Delete only lives in select mode. Alternative: also add Delete to each row’s menu next to Archive (one more destructive item in that menu).
  4. Signed-out listeners can’t delete (S7) so the three free mixes can’t be recycled. Alternative: let them delete, and count deleted mixes toward the three.
